Roundbar installer

Put the Roundbar firmware on a Guition JC3636W518C (ESP32-S3, 360×360 round screen), straight from your browser.

1. Flash the board

Your browser can't talk to USB serial ports. Open this page in Chrome or Edge on a computer. Serial access needs a secure page (https).

No firmware release is published yet. Check back later, or build it from source (see the README).

  1. Use Chrome or Edge on a desktop computer (Firefox and Safari can't access USB serial ports).
  2. Plug the board into the computer with a USB-C data cable.
  3. Click Install Roundbar, pick the board in the list (usually “USB JTAG/serial debug unit” or “ttyACM0”) and confirm. Writing takes a few minutes: the image includes a 9 MB font pack for Chinese, Japanese, Korean and emoji.
  4. When it's done the board restarts into Roundbar.

Board not showing up, or the install fails?

Put it in download mode by hand:

  1. Unplug the board.
  2. Hold the BOOT button, plug the cable back in, then release the button.
  3. Click Install Roundbar again and pick the port that just appeared.

The first install erases the board, including any settings stored on it. If the board already runs Roundbar, update it from the configurator instead (Device page, Firmware card): it only rewrites what changed and keeps your settings.

2. Install the PC app

On Linux (GNOME on Wayland works best), run this in a terminal. It installs the daemon, the configurator and the GNOME extension for your user, and asks for your password once to allow access to the board's USB port.

curl -fsSL https://raw.githubusercontent.com/beedywool-vibecoded/roundbar/master/install.sh | sh

Then open roundbar from your app launcher. Arch users can install roundbar-bin from the AUR; .deb and .rpm packages are attached to each release.
